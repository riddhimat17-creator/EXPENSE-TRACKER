# EXPENSE-TRACKER
a project on EXPENSE TRACKER..
(Python)
A simple command-line Expense Tracker built using Python.
This project helps beginners understand file handling, loops, conditionals, and dictionaries.
# Features
Add expenses with category and amount
View total expenses
View category-wise expenses
Data stored permanently in a text file (expenses.txt)
# How It Works
User selects an option from the menu
Expenses are saved in a file
Program reads data from the file to calculate totals
Concepts Used
while loop
if / elif / else
File handling (open, readlines, write)
Dictionary
String splitting
# How to Run
Copy code
Bash
python expense_tracker.py
